name: bughunt
description: Охота на баги в браузере субагентом bug-hunter с последующими исправлениями.
disable-model-invocation: true
argument-hint: "[на чём сосредоточиться]"
---

Запусти субагента bug-hunter. Фокус: $ARGUMENTS (если пусто — весь готовый функционал).

Когда он закончит:
1. Прочитай новые записи в docs/BUGS.md.
2. Исправляй по важности: для каждого бага сначала убедись, что его тест падает, потом исправляй, потом тест зелёный, потом отметка в BUGS.md.
3. Если баг требует решения по правилам, не выбирай молча — запиши в docs/DECISIONS.md с пометкой «нужно решение».
4. Повторяй охоту, пока новые находки не станут мелкими, но не больше трёх кругов.

В конце отчёт: найдено, исправлено, осталось и почему.
