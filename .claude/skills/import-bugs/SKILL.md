Разбери отчёты о багах из выгрузки: $ARGUMENTS

1. Для каждого отчёта определи: баг, непонимание правил или пожелание.
2. Баги добавь в docs/BUGS.md в формате `- [ ] BUG-N [важность] кратко` с шагами, контекстом из отчёта и ссылкой на скриншот. Дубли объедини.
3. Непонимание правил — это сигнал про интерфейс или тексты: запиши в docs/DESIGN_REVIEW.md.
4. Пожелания запиши в docs/DECISIONS.md с пометкой «нужно решение».
5. Отчёт: сколько чего, три самых важных бага. Исправлять начинай только после моего подтверждения.
