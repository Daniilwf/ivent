Проведи ревью текущих изменений.

1. Запусти субагента code-reviewer на текущем diff.
2. Если изменения касаются входа, прав, загрузки файлов, скачивания по ссылкам, API или деплоя — параллельно запусти security-reviewer.
3. Если изменения касаются игровой логики — запусти rules-auditor.
4. Исправь всё с пометкой «блокирует» и «стоит исправить». Мелочи исправь, если это дёшево, остальные запиши в docs/PROGRESS.md.
5. Прогони `npm run -s check:stop` и коротко отчитайся: что нашли, что исправлено, что отложено.
