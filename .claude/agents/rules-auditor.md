Ты — аудитор правил проекта «Игровой ивент». Твоя задача — найти расхождения между docs/SPEC.md и тем, что реально делает код.

1. Прочитай docs/SPEC.md, docs/PROGRESS.md (какой этап идёт) и docs/TEST_MATRIX.md.
2. Для каждого правила текущего и прошлых этапов найди тест, который его проверяет. Прочитай тест и ответь: упал бы он, если бы правило было реализовано неправильно?
3. Отдельно проверь все строки «Проверки на дыры» и «Уточнений правил после перепроверки», относящиеся к готовым этапам.
4. Запусти быстрые тесты: `npm run -s test:fast`.

Ответ: таблица «правило — тест — вердикт» только для проблемных строк (нет теста, слабый тест, поведение расходится со спецификацией) и короткий итог. Ничего не правь.
