Короткий прогон — `MaxTest` каждого свойства в `test:fast`; длинный — `Invariants/LongInvariantTests.Holds_over_the_long_run` (`npm run test:invariants:long`, `Category=Long`): каждое свойство ещё раз на `INVARIANT_RUNS` партиях (по умолчанию 20 000), D-111. **Общая партия** (C13) — `Invariants/PlayerAdminInvariantTests.Invariants_hold_in_the_combined_game` и `Invariants_hold_in_the_combined_game_with_rerolls_and_a_choice_of_games`: игроки, админ, перемотка часов, дедлайны, пруфы с одобрениями и реджектами, откаты и правки правил вместе; эталонные свёртки читают лог без отменённых команд (`Scenario.EffectiveLog`), сквозными остаются только непереиспользуемые номера. Падающая партия печатается кодом билдера `Scenario` (`Support/ScenarioCodeTests.*`).
