## CI: среднее время прогонов

Обновляется при заметных изменениях. Бюджет — бесплатные минуты GitHub Actions для публичного репозитория.

| Workflow / задание | Когда | Среднее время | Замеры |
| --- | --- | --- | --- |
| CI / Changes and secrets | каждый push и PR | ~10 с | 2026-09-24: 12 с, 10 с |
| CI / Build and fast tests | push с изменениями кода | ~2 мин | 2026-09-24: 1 мин 58 с, 1 мин 41 с |
| CI / E2E | PR в `main` с изменениями кода | ещё не было | — |
