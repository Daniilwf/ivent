# Конфиг правил сезона

Все игровые числа и флаги живут в конфиге сезона. Значения по умолчанию — `docs/ruleset.default.json`. Числа в нём временные, окончательные выставляются после симуляции.

## Правила работы с конфигом

- Конфиг описывается C#-типами в движке. JSON-схема генерируется из этих типов, тест проверяет, что `ruleset.default.json` проходит схему.
- Каждое число, которое использует движок, берётся из конфига. Балансных констант в коде нет.
- Всё, что касается прохождения, фиксируется в снапшоте при ролле. Остальное берётся из текущей версии конфига на момент действия.
- Каждое изменение конфига — новая версия с датой и автором. Игроки видят историю на странице правил.
- Админ правит конфиг как JSON с проверкой по схеме. Невалидный конфиг не сохраняется.
- Новые поля добавляются со значением по умолчанию, чтобы старые версии конфига продолжали читаться.

## Поля

### `features` — флаги функций

| Поле | Что включает |
| --- | --- |
| `mapMode` | `linear` — цепочка клеток из `map.linearLength`, `graph` — карта из редактора |
| `shop`, `items`, `events`, `bets`, `polls`, `achievements`, `weeklyChallenge`, `partnerBoard`, `reactions`, `comments`, `gallery` | соответствующие механики; выключенная механика не видна в интерфейсе и отклоняется движком |

### `season`

| Поле | Значение |
| --- | --- |
| `timezone` | часовой пояс для показа дедлайнов |
| `maxActiveRunsPerPlayer` | сколько прохождений одновременно у игрока |
| `inactiveHintDays` | через сколько дней без действий игрок попадает в подсказку админу |

### `roll`

| Поле | Значение |
| --- | --- |
| `choiceCount` | сколько игр показывается на выбор при обычном ролле |
| `freeRerollsPerRoll` | бесплатные рероллы после каждого ролла |
| `rerollCost` | цена платного реролла: `{ "kind": "coins", "amount": N }` или `{ "kind": "badEvent" }` |
| `techRerollWindowHours` | окно тех-реролла после ролла |
| `minPlayMinutesBeforeDrop` | сколько нужно поиграть до дропа; на совести, используется в подсказках интерфейса |
| `emptyPoolFallback` | что делать, если под фильтрами нет игр: `dropZoneFilter` — снять фильтр зоны |
| `lastDaysLengthFilter` | ограничение длины игр в последние дни сезона, по шагам |

### `reward`

| Поле | Значение |
| --- | --- |
| `diceCount` | число кубов: часы / `hoursPerDie`, округление `nearest`, `floor` или `ceil`, пределы `min` и `max` |
| `dieByDifficulty` | грани кубика по сложности; `grantEvent` — ивент в придачу |
| `challengeBonus` | награда за выполненный челлендж игры |
| `unmetConditionPolicy` | невыполненное условие ивента: `noDiceKeepCoins`, `countAsDrop` или `ignore` |
| `coins` | монетки за прохождение: за час и минимум |
| `coop` | доля очков в коопе и кому достаётся округление |

### `drop`

| Поле | Значение |
| --- | --- |
| `penaltyDice` | штрафной бросок |
| `affectsPoints`, `affectsPosition` | что отнимает штраф |
| `mandatoryEvent` | обязательный ивент при дропе: `bad` или `none` |

### `finish`, `ranking`, `map`

| Поле | Значение |
| --- | --- |
| `finish.requireApprovalForFirst` | первый финиш предварительный до одобрения пруфа |
| `finish.bonusByOrder` | бонус финишировавшим не первыми по порядку финиша |
| `finish.bonusAfterList` | бонус для всех, кто финишировал позже списка |
| `ranking.tiebreakers` | порядок тайбрейков: `completedRuns`, `earliestFinalScore` |
| `map.linearLength` | длина линейной карты в режиме `linear` |

### `economy`

| Поле | Значение |
| --- | --- |
| `allowNegativeCoins` | могут ли монетки уходить в минус от эффектов; покупки в минусе запрещены всегда |
| `inventoryLimit` | лимит объектов в инвентаре |
| `rarityWeights` | веса редкостей в магазине и лутбоксах |
| `shop` | лотов за ролл, время жизни лотов, цена ролла, шаг удорожания реролла, когда цена сбрасывается |

### `effects`

| Поле | Значение |
| --- | --- |
| `maxChainDepth`, `maxEventsPerCommand` | лимиты цепочки эффектов на одну команду |
| `hostileCap` | ограничение одновременных враждебных эффектов на игроке; выключено по умолчанию |
| `attacksOnlyOnHigherPoints` | атаковать можно только тех, у кого больше очков |

### `interactions`, `bets`

| Поле | Значение |
| --- | --- |
| `interactions.inviteTtlHours` | через сколько сгорает приглашение в кооп или на дуэль |
| `bets.maxStake`, `bets.maxOpenBetsPerPlayer` | лимиты ставок |
| `bets.windowHoursAfterRoll` | сколько часов после ролла можно ставить на это прохождение |
| `bets.deadlineOptionsDays` | варианты срока ставки |
| `bets.payoutByHoursPerDay` | коэффициент по нагрузке: часы игры / дни до срока; `upTo: null` — без верхней границы |

### `social`, `nominations`, `weeklyChallenge`

| Поле | Значение |
| --- | --- |
| `social.reactions` | набор эмодзи для реакций |
| `social.galleryUploadsPerDay`, `social.commentsPerDay` | лимиты на человека в день |
| `social.spectatorsCanVote` | голосуют ли зрители |
| `nominations.auto` | автоматические номинации |
| `nominations.voted` | номинации голосованием |
| `weeklyChallenge.defaultRewardCoins` | награда за челлендж недели по умолчанию |
