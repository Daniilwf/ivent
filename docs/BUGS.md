# Найденные баги

Каждая находка: номер, как воспроизвести, что ожидалось, что получилось, важность, падающий тест, отметка «исправлено» (`docs/TESTING.md`, раздел исследовательского тестирования). Номер — задача и порядковый номер находки в ней.

## Открытые

### MP-2. Редактор карты не показывает большую карту целиком

- **Найдено:** ручная проверка RUNBOOK «Как опубликовать карту посреди сезона» на `npm run dev:demo` (2026-11-10, ветка `feat/stage2-close-graph`).
- **Шаги:** админ, раздел «Карта» демо-сезона (89 клеток, 1900×1450) на десктопе 1440×900; кнопка «Показать всю карту».
- **Ожидалось:** кнопка показывает всю карту, пусть мелко.
- **Получилось:** видна середина карты: масштаб не меньше 0,5 (`minZoom` React Flow), карта в рамку не влезает; к краям — перетаскиванием.
- **Важность:** низкая — всё доступно перетаскиванием и списком клеток, публикация не страдает.
- **Отложено:** до дизайн-ревью редактора (сколько мельчить обзор и читаемость подписей — решение дизайна, а не ошибка правил); jsdom не меряет React Flow, проверка — визуальным тестом редактора на большой карте.

### AU4-1. Счётчик, сработавший через `addCounter`, срабатывал снова без конца и ронял процесс

- **Найдено:** аудит правил этапа 4 (2026-11-11).

- **Получилось:** счётчик шёл 1 → 0 → −1 → …, каждое значение не больше нуля снова запускало `Firing.GoOff` мимо лимита цепочки; тестовый процесс падал со Stack overflow, в продукте упал бы единственный потребитель очереди.

### NB-SEC-1. Числа магазина и ставок в правилах сезона не имели границ

- **Найдено:** аудит безопасности 2026-11 (чтение `RulesetValidator`: у экономики проверялись только веса редкостей, у ставок — только ступени выплат).
