# Направления дизайна (G1–G2)

Три визуально разных направления, выросших из предмета: настольная игра, видеоигры, дружеская компания. У каждого — превью главного экрана на данных демо-сезона и демо-пула: `/design-preview/a`, `/b`, `/c` (открываются на любом запуске сайта, например `npm run dev` → http://localhost:5173/design-preview/a). Скриншоты 390×844 и 1440×900 — в `test-artifacts/design/` (не в git), снимаются `node e2e/design-shots.mjs <адрес> test-artifacts/design /design-preview/a /design-preview/b /design-preview/c`.

**Выбор за заказчиком.** До выбора интерфейс (блок H) не строится; после — токены выбранного направления (G3), превью и шрифты остальных удаляются.

Общее у всех трёх: главный экран отвечает «где я, кто лидирует, что делать»; одно главное действие; 16 цветов фишек из набора Окабэ — Ито и его тёмных и светлых вариантов (различимы при дальтонизме); цифры табличные; шрифты — с полной кириллицей, хранятся у нас (npm-пакеты @fontsource, woff2).

## A. «Игровое поле»

Сайт как коробка настольной игры: поле из картонных клеток, толстый контур, настоящие кубики.

| Цвет | hex | Роль |
| --- | --- | --- |
| Стол | `#E6EDF5` | фон страницы |
| Поле | `#FFFFFF` | карточки, поле |
| Чернила | `#1F3160` | контуры, текст (12,6:1 на белом) |
| Чернила мягкие | `#52618A` | второстепенный текст (5,9:1) |
| Солнце | `#F5B700` | единственная главная кнопка, моя клетка |
| Дорожка | `#CFE0F5` | клетки пути; чекпоинты `#B9E3CB` |
| Опасность | `#C23A2B` | дроп, ошибки |

Шрифт: **Rubik** (500, 700, 800) — округлый, дружелюбный, как надписи на коробке; полная кириллица.

```
Телефон                         Десктоп
┌──────────────────────────┐    ┌─────────┬──────────────────────────┬─────────┐
│ Демо-сезон     Дедлайн … │    │ Сейчас  │  ┌──┬──┬──┬──┬──┬──┬──┐  │Лидерборд│
├──────────────────────────┤    │ Katana  │  │Ст│ 2│ 3│ 4│ 5│ 6│…│  │ 1 Бобр  │
│ Сейчас проходишь         │    │ Zero    │  ├──┼──┼──┼──┼──┼──┼──┤  │ 2 Сова  │
│ Katana Zero              │    │[Завер-] │  │20│19│18│…         │  │ 3 Лиса  │
│ [ЗАВЕРШИТЬ] [Дропнуть]   │    │[шить  ] │  └── змейка 10×6 ────┘  │ …       │
│ ⚃ ⚅  Сова: +10           │    │ ⚃ ⚅     │                          ├─────────┤
├──────────────────────────┤    │         │                          │ Лента   │
│ поле: змейка 6×10        │    └─────────┴──────────────────────────┴─────────┘
│ ▦ ▦ ▦ ▦ ▦ ▦              │    Выравнивание: три колонки 320 / гибкая / 320,
├──────────────────────────┤    поле по центру, всё по сетке 4 px.
│ ▔▔ Лидерборд, ты на 3 …  │ ← панель снизу
└──────────────────────────┘
```

Запоминающееся: **картонное поле** — клетки с толстым контуром и сплошной смещённой тенью (без размытия), моя клетка жёлтая, как фишка на столе; кубики — настоящие точки, а не цифры.

Проверка по «Чего избегать»: светлый холодный фон, а не кремовый; без засечек и терракоты; тени не серые размытые, а сплошные контурные — прямо из настольной игры; без КАПСА и «·».

## B. «Сейв-файл»

Сайт как интерфейс игры при дневном свете: рамки HUD, полосы, которые заполняются, пиксельные цифры.

| Цвет | hex | Роль |
| --- | --- | --- |
| День | `#EEF1F8` | фон |
| Панель | `#FFFFFF` | рамки HUD |
| Чернила | `#1D2142` | текст, рамки (15,4:1) |
| Чернила мягкие | `#4F5577` | второстепенный текст (7:1) |
| Индиго | `#4536D9` | главная кнопка, моя клетка |
| Опыт | `#1F9D5C` | полосы очков |
| Здоровье | `#E3405F` | путь до финиша, дроп |
| Золото | `#F2B01E` | первое место, чекпоинты |

Шрифты: **Handjet** (700) — пиксельный с нормальной кириллицей, для цифр и заголовков; **Onest** (400, 600) — основной текст. (Pixelify Sans отброшен: у него «5» читалась как «S», кириллица корявая.)

```
Телефон                         Десктоп
┌──────────────────────────┐    ┌─────────┬──────────────────────────┬─────────┐
│ Демо-сезон [осталось 5дн]│    │ КВЕСТ   │ Карта                    │Лидерборд│
├══════════════════════════┤    │ Katana  │ ▦▦▦▦▦▦▦▦▦▦  уровень 10×6 │ 1 ▣ Бобр│
│ Квест                    │    │ 47/60   │ ▦▦▦▦▦▦▦▦▦▦               │ ████▌ 61│
│ Katana Zero              │    │ ▰▰▰▰▱   │                          │ 2 ▣ Сова│
│ Клетка 47/60  3 место 5ч │    │[Заверш.]│                          ├─────────┤
│ ▰▰▰▰▰▰▰▰▰▱▱ до финиша 13 │    └─────────┴──────────────────────────┴─────────┘
│ [ЗАВЕРШИТЬ] [Дропнуть]   │    Двойные рамки HUD без скруглений, полосы из сегментов.
├══════════════════════════┤
│ уровень: тайлы 6×10      │
│ ▔▔ Лидерборд, ты на 3 …  │ ← панель снизу
└──────────────────────────┘
```

Запоминающееся: **полосы прогресса как в играх** — очки у каждого игрока полосой опыта, путь до финиша полосой здоровья; текущее прохождение — «квест».

Проверка по «Чего избегать»: светлый, а не почти чёрный фон с кислотным акцентом; пиксельный шрифт — не моноширинный и только для цифр и заголовков, мелкие подписи обычным Onest; нулевое скругление здесь из предмета (HUD), а не газетная вёрстка — рамки двойные и плотные, без тонких линеек.

## C. «Компания»

Сайт как чат друзей: игроки — стикеры с белой обводкой, лента — сообщения, путь на карте нарисован маркером.

| Цвет | hex | Роль |
| --- | --- | --- |
| Бумага | `#F4F5FB` | фон (холодный, не кремовый) |
| Карточка | `#FFFFFF` | панели |
| Чернила | `#17151F` | текст (18:1) |
| Чернила мягкие | `#5B5870` | второстепенный текст (6,6:1) |
| Фиолетовый | `#5B3DF5` | карточка текущего прохождения, «я» |
| Солнце | `#FFC83D` | главная кнопка, первое место |
| Небо | `#2AA7F5` | маршрут на карте |
| Розовый | `#FF4F93` | опасность |

Шрифты: **Unbounded** (600, 800) — широкий гротеск для заголовков и цифр; **Onest** (400, 600) — основной текст.

```
Телефон                         Десктоп
┌──────────────────────────┐    ┌─────────┬──────────────────────────┬─────────┐
│ Демо-сезон               │    │▓(Л)Сейч.│ ●-·-●-·-●-·-●-·-●  маршрут│Лидерборд│
│ Дедлайн 1 октября, 21:00 │    │▓ Katana │ ●-·-●-·-●-·-●-·-●        │ (Б) 61  │
├──────────────────────────┤    │▓[Заверш]│                          │ (С) 58  │
│▓ (Л) Сейчас проходишь   ▓│    └─────────┤                          ├─────────┤
│▓ Katana Zero            ▓│              │                          │ Лента   │
│▓ [Action] [Indie] …     ▓│              │                          │(С) ○○○  │
│▓ [ЗАВЕРШИТЬ] (Дропнуть) ▓│              └──────────────────────────┴─────────┘
├──────────────────────────┤    Скругления 20 px у карточек, пилюли у кнопок,
│ маршрут маркером 6×10    │    лента пузырями сообщений.
│ ▔▔ Лидерборд, ты на 3 …  │ ← панель снизу
└──────────────────────────┘
```

Запоминающееся: **стикеры игроков** (круглые, с белой обводкой и лёгким наклоном) и **маршрут, нарисованный маркером** пунктиром; лента — как переписка в общем чате.

Проверка по «Чего избегать»: фон холодный, не кремовый; карточки не одинаковые серые с тенью — главная фиолетовая, остальные белые без теней; без декоративных градиентов, КАПСА, «·», «→» и нумерации 01/02/03.
