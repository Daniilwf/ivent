## G3 «Дизайн-система», `/styleguide` (2026-09-26)

Скриншоты: `test-artifacts/g3/`, `test-artifacts/g3b/`, `test-artifacts/g3-review/` (не в git).

| Находка | Решение |
| --- | --- |
| Фокус на карте не виден: кольцо у svg обрезает рамка | Кольцо на рамке карты через `has-[svg:focus-visible]`, у svg своё кольцо выключено |
| В колонке «Фокус» стайлгайда нет кольца: `data-force` не включает `:focus-visible` | Кольцо — утилита `focus-ring`, компоненты берут его через `is-focus:`, одинаково для настоящего и показанного фокуса |
| При reduced motion мерцают скелетон и спиннер (бесконечная анимация по 1 мс) | `animation-iteration-count: 1` в правиле reduced motion, скелетон и спиннер без анимации |
| Моменты длиннее 3 с (колесо с промахом 3,4 с, долгий ход 4,4 с) | Бюджет `momentBudget` 2,6 с: колесо делит его между промахами, фишка прыгает быстрее на длинном ходе |
| «Я» (#c2410c) почти как фишка 6 и рядом с красным «Дропнуть» | «Я» — фиолетовый #6d28d9, которого нет среди фишек и значений; плюс подпись «ты» |
| Загрузка выглядит как «отключено» | Загрузка — полный цвет, спиннер и курсор ожидания; бледность только у отключённой |
| Результат момента дважды: карточка и жирный абзац | Слова результата — только для экранных чтецов (`sr-only`); в карточке колеса название игры — заголовок |
| Теги и скелетоны сливаются с фоном | Токен `--color-muted` для тихих заливок |
| Слишком много чёрных рамок | Чёрный контур — у того, что нажимают, и у моментов; панели, карточка игры, состояния — без рамки, статусы — полоса слева |
| Синий — и главное действие, и украшение | Крыши города деревянные, указатель колеса золотой |
| Карта на телефоне: 40% пустого стола и мелкие подписи | Высокая рамка открывается по высоте доски вокруг моей фишки |
| Кнопки масштаба закрывают клетки | Кнопки в ряд внизу рамки |
| Стикер первого закрывает подпись «Финиш» | На старте и финише стикер стоит выше |
| Кнопки в стайлгайде за горизонтальной прокруткой, навигация 32 px, моноширинные подписи | Состояния кнопок переносятся строками, навигация 44 px, подписи обычным шрифтом |
| Кнопка закрытия панели без рамки | `IconButton` |

Отложено: подписи колеса после остановки бывают вверх ногами (колесо крутится вместе с ними, как настоящее); длинное название в карточке игры переносится целиком, без обрезки.

## H1 «Каркас» (2026-09-26)

Скриншоты: `test-artifacts/h1/`, `test-artifacts/h1b/`, `test-artifacts/h1-review/` (не в git).

| Находка | Решение |
| --- | --- |
| Шапка на телефоне ломается: кнопка бага сжимается, название переносится, знак «нет связи» выталкивает меню за экран | `shrink-0` у кнопок шапки, название без переноса, на телефоне знак связи — иконка, имя — только для чтецов; шапка в `/styleguide` на 390 px без связи |
| Фокус пропадает после окна бага и после «Сменить пароль» | Окно возвращает фокус на кнопку бага; меню не забирает фокус, если пункт открыл новый экран; форма ставит фокус на свой заголовок, возврат — на меню |
| Ошибки проверки внизу формы, а не у поля | Ошибки проверки — у поля (`role="alert"`, `aria-invalid`), плашка — только ответ сервера |
| Смешаны «ты» и «вы» | Весь словарь на «ты» |
| Нажатие на кнопку бага ничего не показывает, пока снимается страница | Кнопка крутит спиннер |
| Выделенный пункт меню почти не виден | Выделение — заливка `muted` и контур; у кнопки меню вид «открыто» |
| Загрузка мигает серым перед входом на столе | Загрузка — на столе |
| Кольцо фокуса прилегает к названию; подпись ссылки не совпадает с текстом | Отступ у ссылки, лишняя `aria-label` убрана |
| Красная полоса слева у ошибок — шаблонный акцент | Убрана: иконка и фон |
| Повторы в словаре | Убраны |
| Код: знак «нет связи» мог остаться после ухода со страницы | Учёт по подпискам, тесты на остановку во время старта и переподключения |

Отложено: пустое состояние «Сезон ещё не начался» на десктопе — маленькая карточка сверху; появится смысл, когда будет что показать рядом (H2).
